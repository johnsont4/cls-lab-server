# CLS Lab Server

Hello! Welcome to the [CLS Lab](https://cls-lab.com/) server guide. I'd recommend that you start in the server-info.md or gaining-access.md files. Then depending on your desires, check out the flask-deployment.md, potato-deployment.md, or the various (temporarily (hopefully)) scattered sh files with commands I've found helpful on both the lab server and the CURC cluster.

Please update this repo as you find inconsistencies or changes. The lab server is a living, constantly changing entity. This documentation will go out of date without your help!
